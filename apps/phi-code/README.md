# PHI CODE

**Information exists between frames.**

情報はフレームとフレームの間に存在する。ファイ現象から着想した光学通信の実験です。24×24のマスの点滅をスマートフォンのカメラで読み取り、共有した秘密鍵で文章を復号します。AES-256-GCM、文章圧縮、受信フレームの補完に対応。AIやAPIキーを必要とせず、端末内で処理するPWAです。

- [Open PHI CODE](https://phi-code.pages.dev/)
- [MASATO LAB](https://masato-lab.pages.dev/)

## 使い方
同じ秘密鍵を送信端末・受信端末に入力し、送信側の TRANSMIT / LARGE VIEW から開始。受信側で SCAN を選び、四隅のマーカーをカメラ内に収めます。

24×24 / AES-256-GCM / 最大20,000 UTF-8 bytes / PWA / ローカル処理。

実験版です。端末や照明によって読み取り速度は変わります。光刺激に敏感な方は使用を避けてください。独自の光学表現は暗号そのものの安全性を保証するものではありません。
