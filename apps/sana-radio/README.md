# SANA RADIO

架空の世界のニュース、天気予報、深夜トーク、エッセー朗読、インストゥルメンタルDUBを短波ラジオの操作で聴けるPWAです。放送はSANA語で、字幕は日本語と英語から選べます。

[MASATO LABで開く](https://masato-lab.pages.dev/apps/sana-radio/)

OpenAI APIキーは任意です。設定するとNEWS・WEATHER・MIDNIGHTで新しい台本を作れます。MUSICは選局中に次のDUBを自動で編曲します。キーはブラウザからOpenAIへ直接送信します。

このディレクトリを静的HTTPサーバーで配信すると動作します。PWAのインストールにはHTTPSまたはlocalhostが必要です。言語データと音声素材の出典は同梱の通知ファイルをご覧ください。
