# DUB RIDDIM

**A complete DUB rhythm machine**: program six parts (kick, snare, hi-hat, bass, skank, bubble), edit notes in a piano roll, arrange four patterns into a song, and perform live dub effects.

**Play the current version:** https://dub-siren.sunny-seed-0354.chatgpt.site/

## What it does

- Create and edit notes in a piano-roll sequencer, with position, length and velocity editing.
- Arrange a rhythm and bass line; change keys and chords.
- Perform dub effects in real time using the DUB SPACE pad.
- Use the separate REWIND sound.
- Save work and export WAV audio in the hosted app.
